MUZAKULA — оновлена версія сайту
1. Розпакуйте ZIP.
2. Замініть index.html, style.css, script.js та папку assets у репозиторії GitHub.
3. Після завантаження дочекайтеся зеленого статусу GitHub Pages.
4. На сайті натисніть Ctrl+F5.
